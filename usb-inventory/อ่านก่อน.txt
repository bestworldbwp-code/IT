โปรแกรมเก็บข้อมูลเครื่อง (IT Asset · เบสท์เวิลด์ อินเตอร์พลาส)
================================================================

วิธีใช้
  1. คัดลอกโฟลเดอร์นี้ทั้งโฟลเดอร์ลง USB
  2. ที่เครื่องพนักงาน เสียบ USB แล้วดับเบิลคลิก "เก็บข้อมูลเครื่อง.bat"
  3. พิมพ์รหัสเครื่องบนสติกเกอร์ เช่น COM-IT-05 แล้วกด Enter รอประมาณ 30 วินาที
  4. ขึ้น "Saved / บันทึกแล้ว" กด Enter ปิด แล้วไปเครื่องถัดไป
     - Windows หรือโปรแกรมป้องกันไวรัสเตือน: กด More info / Run anyway หรืออนุญาต (เป็นสคริปต์ของเราเอง)
     - คลิกขวาที่ .bat แล้วเลือก Run as administrator จะได้ข้อมูล BitLocker / TPM / Secure Boot เพิ่ม (ไม่บังคับ)
     - เก็บเครื่องเดิมซ้ำได้ จะเขียนทับของเดิม ถ้าพิมพ์รหัสซ้ำกับเครื่องอื่น โปรแกรมจะเตือนก่อน

ผลลัพธ์ (โฟลเดอร์ data บน USB)
  inventory.json   นำเข้าระบบ: เมนู เครื่องมือ → นำเข้าข้อมูลเครื่อง (USB) → เลือกไฟล์นี้
                   ระบบจะเติม S/N, CPU, RAM, Disk ในทะเบียน FQP-IT-01:01 และประวัติเครื่อง FQP-IT-01:02
  inventory.csv    สรุปทุกเครื่อง เปิดด้วย Excel
  software.csv     โปรแกรมที่ติดตั้งทุกเครื่อง ใช้นับลิขสิทธิ์ (กรองคอลัมน์ "โปรแกรม" ใน Excel)
  <รหัส>.json      ข้อมูลละเอียดของแต่ละเครื่อง

เก็บอะไรบ้าง
  ตัวเครื่อง : ยี่ห้อ/รุ่น, S/N, เมนบอร์ด, BIOS, CPU, RAM แต่ละแถว, ดิสก์ (SSD/HDD ขนาด S/N สุขภาพ),
               พื้นที่ว่างแต่ละไดรฟ์, การ์ดจอ, จอ (ยี่ห้อ/รุ่น/S/N), แบตเตอรี่
  Windows    : รุ่น, build, วันที่ติดตั้ง, แท้หรือไม่, อัปเดตล่าสุด, Firewall, BitLocker/TPM/Secure Boot (ต้อง admin)
  โปรแกรม    : ทุกโปรแกรมที่ติดตั้ง, Office, Antivirus
  เครือข่าย   : IP, MAC, Wi-Fi ที่ต่ออยู่, ไดรฟ์ที่แมป, เครื่องพิมพ์ที่ติดตั้ง (รวม IP ของเครื่องพิมพ์เครือข่าย)
  ผู้ใช้       : คนที่ล็อกอินอยู่, โปรไฟล์ผู้ใช้ในเครื่อง, บัญชีในเครื่อง, ใครเป็น admin

ไม่เก็บ: รหัสผ่าน, product key, ไฟล์งานหรือข้อมูลส่วนตัว, ประวัติเว็บ และไม่ส่งข้อมูลออกอินเทอร์เน็ต

ข้อควรระวัง: ไฟล์ใน data มี IP ชื่อผู้ใช้ และรายชื่อ admin ของทุกเครื่อง เก็บ USB ให้ดี อย่าให้คนอื่นยืม
